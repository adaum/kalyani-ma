# Kalyani Ma

Pure static site. Vercel serves `index.html` and `turn-the-bottle-around.html` from the repo root, with images in `images/`.

There is no Node or Next.js build step.

Local visual editing uses VvvebJs, which lives outside this repository at `~/tools/vvvebjs` and is started with `~/tools/vvvebjs/start-editor.sh`.
